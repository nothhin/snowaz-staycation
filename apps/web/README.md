# SnowAZ Staycation

Direct-booking and availability website for SnowAZ Staycation at Urban Deca Homes Banilad, Mandaue City.

## Development

From the repository root:

```bash
npm install
npm run dev --workspace web
```

Quality checks:

```bash
npm run lint
npm run typecheck
npm test
npm run build
```

Live availability and booking requests require the server-side database environment variables documented in `.env.example`.
